Редактор сайта SPOTTER

Правки отсюда сразу уходят в репозиторий, и сайт пересобирается сам. Нужен личный токен GitHub — он сохранится в этом браузере, вводить каждый раз не придётся.

  1. Откройте страницу создания токена.
  2. Repository access → Only select repositories → выберите jurydes/spotter.
  3. Permissions → Repository permissions → Contents → Read and write.
  4. Срок действия — на ваше усмотрение; когда истечёт, просто выпустите новый.
  5. Нажмите Generate token и вставьте его сюда.

Снимите галочку на чужом или общем компьютере — тогда токен забудется, как только вы закроете вкладку.
