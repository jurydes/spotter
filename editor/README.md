# Редактор сайта

Замена админке на Netlify. Правит выпуски и товары, заливает фото,
коммитит всё прямо в репозиторий — сайт пересобирается сам.

## Зачем понадобилась

Прежняя админка (Decap CMS) входила через Netlify. У Netlify кончились
бесплатные кредиты, деплои встали — и вместе с ними замёрзла админка:
она застряла на версии от 8 сентября и не знала про поля, добавленные
позже. Сохранение товара через такую форму стёрло бы их из `data/merch.json`.

Здесь посредника нет вообще. Страница ходит в GitHub API напрямую,
вашим личным токеном. Ломаться нечему: ни Netlify, ни сервера,
ни OAuth-приложения.

## Как открыть

**С компьютера, без всякой публикации** — просто откройте в браузере
файл `editor/index.html` из папки проекта. Этого достаточно: страница
работает с GitHub по сети, локальный сервер ей не нужен.

Если понадобится доступ с телефона — скажите, выложим на
`spotterlive.ru/editor`, туда же, куда деплоится сайт.

## Токен

Нужен один раз, дальше сохранится в браузере.

1. <https://github.com/settings/personal-access-tokens/new>
2. **Repository access** → *Only select repositories* → `jurydes/spotter`
3. **Permissions** → *Repository permissions* → **Contents: Read and write**
4. **Generate token**, скопировать и вставить в редактор.

Срок действия — на ваше усмотрение. Когда истечёт, редактор скажет
«Токен не принят» — выпустите новый и вставьте снова.

Токен лежит в `localStorage` этого браузера и уходит только на
`api.github.com`. Это нормально, пока редактор один человек: общий
токен на команду выдавать нельзя, там понадобился бы полноценный вход.

## Что умеет

* **Выпуски** и **Мерч** — те же поля и подсказки, что были в старой админке,
  плюс новые: «Показывать на сайте», «Всего в тираже», «Осталось штук».
* Добавить, удалить, переставить запись (стрелками).
* Загрузить фото, переставить и удалить; первое фото — главное.
* Сохранение по разделам: правите мерч — коммитится только `data/merch.json`.

## Фото сжимаются сами

Снимок с телефона приезжает на 8 МБ при 4000 пикселей по стороне,
а показывается в разы меньшем размере. Поэтому перед отправкой редактор
сам ужимает картинку до 1600 пикселей по длинной стороне и жмёт в JPEG:
вес падает примерно в двадцать раз, на глаз разницы нет.

Заодно прозрачный фон заливается белым, а не чёрным. Это не мелочь:
на сайте уже висело фото худи с серой шашечкой вместо фона — его
вырезали в редакторе и сохранили в JPEG, который прозрачности не знает.

Имя файла переводится в латиницу и получает отметку времени, поэтому
новая загрузка никогда не затирает уже лежащее фото.

## После сохранения

Коммит уходит в `main` → GitHub Actions собирает сайт → бакет Yandex.
Обычно пара минут. Отдельно ничего запускать не нужно.

## Если что-то пошло не так

| Сообщение | Что делать |
|---|---|
| Токен не принят | Истёк или скопирован не целиком — выпустите новый |
| Доступ запрещён | У токена нет права **Contents: Read and write** |
| Репозиторий не найден | Токен выдан не на `jurydes/spotter` |
| Файл изменился, пока вы правили | Кто-то (или я) закоммитил параллельно — обновите страницу и повторите |

Последнее — не ошибка, а защита: редактор запоминает версию файла,
который открыл, и GitHub не даст записать поверх чужой правки вслепую.

## Старая админка

`admin/` пока оставлена на месте. Когда убедитесь, что редактор
устраивает, её можно удалить вместе с зависимостью от Netlify.
