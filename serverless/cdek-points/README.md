# Пункты выдачи СДЭК на сайте

При выборе «Доставка» покупатель выбирает пункт выдачи. Есть три режима,
и сайт сам переключается между ними по тому, что заполнено в `js/config.js`:

| Что заполнено | Что видит покупатель |
|---|---|
| ничего | обычное текстовое поле «адрес доставки» |
| `cdekPointsUrl` | поиск пунктов списком по городу, «сначала ближайшие ко мне» |
| `cdekPointsUrl` + `cdekWidgetKey` | **официальный виджет СДЭК с картой** |

Режимы идут лесенкой: можно включить функцию и пользоваться списком,
а карту добавить потом. Если виджет почему-то не загрузится, сайт молча
вернётся к списку — выбрать пункт человек должен в любом случае.

## Почему нельзя проще

Пробовал напрямую из браузера — не выйдет:

* `integration.cdek.ru/pvzlist/v2/xml` (старый открытый список) — **410**, закрыт;
* `api.cdek.ru/v2/deliverypoints` без токена — **401**;
* публичные тестовые ключи из старых статей — **invalid_client**, отозваны.

Плюс у `api.cdek.ru` нет CORS-заголовков: даже с ключом браузер ответ
не отдал бы странице. Виджет это не обходит — в его же пакете лежит
`service.php`, который делает ровно то же самое на стороне сервера.
Функция из этой папки — порт этого `service.php` на Node.

## Шаг 1. Ключи СДЭК

1. Зарегистрируйтесь как клиент на <https://www.cdek.ru/> (для ИП и самозанятых —
   договор оформляется онлайн).
2. Войдите в личный кабинет → раздел **«Интеграция»** (или **«Настройки → API»**).
3. Создайте **учётную запись для API** и скопируйте два значения:
   * **Account / Клиент** — логин интеграции;
   * **Secure password / Секретный ключ** — пароль.
4. Пока договора нет, можно проверить всё на песочнице: те же шаги
   в <https://api.edu.cdek.ru>, ключи запрашиваются у `integrator@cdek.ru`.

Эти два значения нигде на сайте не появляются — они живут только
в переменных окружения функции.

## Шаг 2. Функция в Яндекс Облаке

Тот же аккаунт, где лежит бакет `spotterlive`.

1. **Cloud Functions** → **Создать функцию** → имя `cdek-points`.
2. Создать версию:
   * среда выполнения — **nodejs18**;
   * способ — **Редактор кода**, файл `index.js` — содержимое
     [`index.js`](index.js) из этой папки;
   * точка входа — `index.handler`;
   * таймаут — **10 секунд**, память — **256 МБ**.
3. Переменные окружения:
   | Имя | Значение |
   |---|---|
   | `CDEK_ACCOUNT` | логин интеграции из шага 1 |
   | `CDEK_PASSWORD` | секретный ключ из шага 1 |
   | `CDEK_API` | только для песочницы: `https://api.edu.cdek.ru` |
4. Вкладка **Обзор** → включить **«Публичная функция»**.
   Без этого сайт получит 403.
5. Скопировать ссылку для вызова — вида
   `https://functions.yandexcloud.net/d4e...`

В `js/config.js`:

```js
cdekPointsUrl: 'https://functions.yandexcloud.net/d4e...',
```

На этом уже работает выбор пунктов списком. Проверить:

```
https://functions.yandexcloud.net/d4e...?city=Москва
```

Должен вернуться JSON со списком `points`. Если пришло
`{"message":"Не удалось получить данные СДЭК"}` — смотрите логи функции
в консоли облака: там будет настоящая причина (чаще всего неверные ключи).

## Шаг 3. Карта (ключ Яндекс.Карт)

Виджету нужен собственный ключ Яндекса — СДЭК рисует карту чужими руками.

1. <https://developer.tech.yandex.ru/services> → **Подключить API**.
2. Выбрать **«JavaScript API и HTTP Геокодер»** — именно эту пару:
   виджет показывает карту через JS API и ищет адреса через Геокодер,
   на раздельных ключах половина функций не заработает.
3. Заполнить форму (бесплатного тарифа хватает на витрину такого размера),
   дождаться выдачи ключа.
4. **Обязательно ограничить ключ доменом** `spotterlive.ru`
   в настройках ключа. Этот ключ виден в исходниках страницы любому
   посетителю — без ограничения вашу квоту израсходуют чужие сайты.

В `js/config.js`:

```js
cdekWidgetKey: 'ваш-ключ-яндекс-карт',
cdekDefaultCity: 'Москва',   // с какого города открывается карта
```

Запушить — и вместо списка появится кнопка «Выбрать пункт на карте».

## Про сам виджет

* Лежит у нас же: `js/vendor/cdek-widget.4.0.0.umd.js` (официальный пакет
  `@cdek-it/widget`, 680 КБ). Отдаётся с нашего домена, а не с чужой CDN, —
  так он не зависит от доступности стороннего хостинга.
* **Грузится только по нажатию** кнопки «Выбрать на карте»: платить
  семьюстами килобайтами за каждый заход на сайт незачем, до корзины
  доходят единицы.
* Открывается поверх страницы окном, не ломая вёрстку узкой корзины.
* Доставка курьером до двери в нём скрыта намеренно: у проекта нет ни
  тарифа, ни склада отправки — только выдача в пункте.
* Стоимость доставки не считается: для этого виджету нужен город
  отправления и габариты посылки, а у предзаказа их пока нет. Цену
  доставки согласуете в переписке. Если захотите включить расчёт —
  добавьте в параметры виджета `from` и `goods` (функция действие
  `calculate` уже поддерживает).

### Если будете обновлять виджет

Виджет сверяет заголовок `X-Service-Version` из ответа функции со своей
версией и **отказывается работать при расхождении мажорной цифры**.
Поэтому при замене файла на новую мажорную версию поменяйте и
`WIDGET_VERSION` в [`index.js`](index.js), иначе карта будет молча
показывать ошибку загрузки.
